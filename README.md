#  (R Shiny)

## Overview
This project is an interactive Sales Dashboard built using R Shiny and the Sample Superstore dataset.

## Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Sales by Category
- Profit by Region
- Monthly Sales Trend

## Tools Used
- R
- Shiny
- ggplot2
- dplyr
- tidyverse
